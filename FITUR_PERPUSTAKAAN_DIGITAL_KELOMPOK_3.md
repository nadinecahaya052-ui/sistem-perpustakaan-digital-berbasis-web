# Perpustakaan Digital Kelompok 3

Paket ini adalah proyek mandiri Perpustakaan Digital Kelompok 3 dan mengikuti referensi screenshot yang diberikan.

## Menu utama admin
- Dashboard / Data Buku
- Tambah Buku
- Cari Buku
- Data Anggota (Siswa)
- Data Peminjaman
- Data Denda
- Riwayat Peminjaman

## Data master
- Admin
- Anggota
- Buku
- Stok Buku
- Jenis Buku
- Jurusan
- Kategori Buku
- Kelas
- Klasifikasi DDC
- Sumber Buku

## Transaksi & laporan
- Peminjaman Buku
- Pengembalian
- Denda keterlambatan
- Kas
- Pengunjung
- Laporan transaksi
- Laporan anggota
- Cetak label buku
- Kartu anggota

## Siswa
- Login
- Register/Sign Up
- Lupa password
- Profil
- Katalog/cari buku
- Detail buku
- Form peminjaman maksimal 3 buku
- Batas pengembalian otomatis 7 hari
- Riwayat peminjaman

## Aturan transaksi
- Maksimal 3 buku aktif per siswa.
- Jangka peminjaman 7 hari.
- Denda default Rp1.000 per hari keterlambatan.
- Stok berkurang saat peminjaman dan bertambah saat pengembalian.
